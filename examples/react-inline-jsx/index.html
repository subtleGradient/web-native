Inline browser transform

JSX in the page.

This is the old browser JSX trick updated for React 19: the page imports React through an import map, Babel transforms this inline JSX script at load time, and the result executes as a native ESM module.

Loading React from ESM and transforming JSX...

What proves it

  • The React imports are bare specifiers resolved by the import map.
  • The JSX script is not a module script; Babel turns it into one with data-type="module".
  • No npm install, bundler, transpiler process, or generated file is involved.
