ai.web component stories

Fixture-backed examples for the browser-native AI elements. These stories document the current OpenAI-shaped behavior without making a live network request.

Client, key field, and result

openai-client owns request state. openai-key-field writes an API key into that client. openai-result renders the latest text, JSON, image, or error result emitted by the client.

<openai-key-field target="fixture-ai"></openai-key-field>
