OpenAI demos

Pick a focused demo. Each page owns one request shape and is wired to the Codex broker exposed by the local runner.

Text Send instructions and a prompt to the Responses API. Image Generate an image through the Responses image generation tool. Embedding Create an embedding vector for input text. Web search Use the hosted web_search tool with citations. File search Query a pre-populated vector store. Code interpreter Run hosted Python in an ephemeral container. Computer use Request computer_call actions for a harness to execute. Remote MCP Call a public demo MCP server. Tool search Demonstrate deferred tool loading with tool_search.
